## Shortlist and cuts

The library search covered digital/UI-native, print/craft, and historical identities, plus a personal-site direction:

| Identity | Family | Decision |
|---|---|---|
| ASCII / text-mode art | Digital / UI-native | Kept in A. It directly answers the requested ASCII trait and the user's developer-tool work. The ASCII block is labelled and hidden from assistive technology so glyphs do not become screen-reader noise. |
| Terminal / CLI | Digital / UI-native | Kept in A as the framing around ASCII. It signals automation without making the page itself a fake terminal. |
| Technical drafting | Print / craft | Kept in B. A measured grid, annotations, and a real project capture support the data-lineage story. |
| Data-viz-as-hero | Digital / UI-native | Cut as a standalone direction: an animated chart would make one project's data the main event and risks decorative or inaccessible data. Its evidence-first idea remains in the project image and copy. |
| Bento grid | Digital / UI-native | Cut: its capability mosaic would read like a product feature page and flatten the case-study narrative. |
| Indie web / small web | Digital / UI-native | Cut: guestbook/badge conventions lean hobbyist and conflict with the recruiter-first purpose and high-end brief. |
| Editorial design | Print / craft | Cut as the primary grammar: a magazine spread assumes more original photography than the one verified project capture available. |
| Swiss design | Historical | Cut as a separate option: a strict grid alone could collapse into a generic software portfolio and overlap with technical drafting. |
| Swiss Punk / New Wave typography | Historical | Kept in C as the unexpected candidate. The grid visibly breaks through stepped type and layered print-like composition while body copy stays readable. |

## Live reference probes

The six sites below were opened in Chromium at 1440 × 900. Measurements are observations of the current pages, not claims about what their authors intended.

- [Charm](https://charm.sh/) loaded with HTTP 200 and no page errors. Its current page uses a vivid purple/blue gradient, large product copy, and a terminal-shaped media block. Useful for seeing how terminal culture can be marketed; its palette and product framing were rejected for this personal portfolio.
- [Vercel](https://vercel.com/) loaded with HTTP 200 and no page errors. The current hero is a light page with the heading “Agentic Infrastructure,” a centered black triangular graphic, and compact CTAs. It no longer shows the blueprint-grid details listed in older drafting references, so it was rejected as a current visual model.
- [Hex](https://hex.tech/) loaded with HTTP 200 and no page errors. The current page exposes analytics and AI-product copy; the captured viewport showed a dotted technical field but not a fully rendered hero during the probe window. Kept only as a lead for measured technical surfaces, not as direct composition evidence.
- [Made in Space](https://madeinspace.la/) loaded with HTTP 200 and no page errors. Its current homepage uses oversized, spatially offset type and floating project imagery on a mint field. Selected for C's asymmetry and typography; the mint palette and exact composition are not carried over.
- [Swissted](https://swissted.com/) loaded with HTTP 200 and no page errors. Its first viewport presents a dense row of geometric concert-poster artworks. It supports poster-scale, print-led composition, but its shop structure is not used.
- [Ghostty](https://ghostty.org/) returned HTTP 200 but rendered a blank viewport and empty body text in the probe. Rejected as observable evidence; Charm was used instead for the terminal-family comparison. The ASCII grammar itself remains grounded in the library entry and Nilson's explicit request.

## Audition set

All candidates use the same headline, biography, three projects, bilingual copy, and LinkedIn contact action. They differ in identity only:

- **A — Terminal + ASCII:** dark, instrument-like layout; a legible workflow diagram and text-mode accents. The High option is a wireframe 3D data-lineage form, estimated from the skill's measured reference at about 180 KB of motion code.
- **B — Technical drafting:** warm paper, measured dot grid, annotations, and the repository screenshot treated as a figure. The High option is a GPU particle field, with the skill reference reporting up to about 340 KB of motion code.
- **C — New Wave editorial:** oversized stepped typography, one red accent, and a rotated halftone-like treatment of the user's project screenshot. A custom High halftone projection is not measured yet; its final payload must be measured before shipping.

The audition files are identity studies, not final-site specifications. After selection, the chosen effect and actual image weight will be priced again before the production build.
